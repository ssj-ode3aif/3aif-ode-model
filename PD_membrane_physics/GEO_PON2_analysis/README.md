# GEO PON2 re-analysis

Supplementary code and processed data for the bioRxiv preprint:

A coupled mitochondrial and endoplasmic reticulum membrane-failure model of Parkinson's disease

Authors: Sungsoo Jung and Chun Geun Lee

## Contents

- SupplementaryCode_PON2_reanalysis.zip: analysis scripts, processed inputs, sample-inclusion table, software/package details, statistical outputs, and code to regenerate Supplementary Figure 2.

## Public datasets

The analysis reuses publicly available Parkinson's disease substantia-nigra datasets from GEO:

- GSE7621
- GSE20292
- GSE49036
- GSE157783

## Scope

This repository reports no new clinical or human-subjects data. The analysis is a re-analysis of public omics datasets and supports the mechanistic model presented in the preprint.
